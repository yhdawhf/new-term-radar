## 定时配置

正式规则继续保留：

- `0 */8 * * *`：北京时间每天 00:00、08:00、16:00，sources 检查 Hugging Face 模型和 Spaces。
- `30 1 * * *`：北京时间每天 09:30，daily 检查 GitHub 和 Glama 等日报信号。

实际运行有延迟。例如 10 月 22 日的 `cron=30 1 * * *` 日报实际到北京时间 14:23 才开始。计划时间不是保证送达时间；每轮的 event、cron、实际开始时间和 commit 均保存在 trigger.json。

定时工作流从 main 检出当前代码，同步 main 后不需要另复制一份程序或重新填写 Secret。免费功能保护、已有快照、已发送词和待发队列继续保留。
